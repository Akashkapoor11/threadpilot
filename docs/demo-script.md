# ThreadPilot - 3 to 5 minute demo script

## 0:00 - 0:30 | Frame the problem

“Architecture projects already contain the information. The coordination black hole is the missing relationship between a change and the people, dependencies, approvals and actions it creates.”

Open the Command Center for Riverside Residence.

Point to the critical signals, open blockers and approval gate metrics.

## 0:30 - 1:10 | Evidence-backed intelligence

Open **A-305 Rev 05 supersedes Rev 04**.

Say:

“ThreadPilot is not just storing a message. It has connected the evidence to a coordination consequence, identified the owner, and exposed the next action.”

Open the evidence messages and the impact chain.

## 1:10 - 1:45 | Dependencies become visible

Open **Impact Graph**.

Trace the current relationship chain from change to downstream work.

Say:

“The graph is generated from coordination signals. The seeded Riverside scenario makes the judging path reproducible, while newly captured signals can extend the graph.”

## 1:45 - 2:10 | Action and alert

Open **Action Queue**.

Confirm the P0 MEP coordination action.

Return to the signal drawer and queue an alert to MEP Consultant.

Say:

“A detected consequence becomes an accountable action. The routing event and human decision are auditable.”

## 2:10 - 3:05 | Prove the API-first path

Open **Capture update**.

Use this unseen example:

> “The marble supplier cancelled the lobby order. A replacement is available, but the finish schedule and client approval must be updated before fabrication can start.”

Click **Preview intelligence**.

When the LLM key is configured, point to:

**LLM API · PRIMARY**

Explain:

“The provider is our primary extraction path. It produces structured coordination intelligence - signals, owner, dependencies, approvals, blockers and next actions.”

If the provider is unavailable, the UI shows:

**LOCAL · FALLBACK**

Say:

“The fallback keeps the system useful and explainable instead of failing closed.”

## 3:05 - 3:35 | Save and watch the state change

Click **Save + route**.

Open Signals and point out the newly created signal. Open Actions and show the new owner action.

Open Impact Graph and point out the new graph nodes.

This proves the system is not only replaying the seeded scenario.

## 3:35 - 4:00 | Project memory

Open **Project Memory**.

Show the captured source message and the audit event.

Close with:

“ThreadPilot does not replace the coordinator. It turns fragmented evidence into a reviewable consequence chain so the team can act before the project pays for the handoff.”
